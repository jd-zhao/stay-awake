# Contributing

Report bugs with the app version, macOS version, Mac model, reproduction steps and expected behavior through [Issues](https://github.com/jd-zhao/stay-awake/issues).

For changes, keep the menu bar interface compact and native, preserve System appearance, and test both light and dark modes. Changes to power management must preserve manual lock, stop/quit cleanup and session deadlines.

Before submitting a pull request, build the app and run the self-check as described in [Development](docs/DEVELOPMENT.md). For UI changes, also check field sizing, keyboard editing and the end-time form in both appearances.
